# Documentation curator

## Purpose

Keep the RoModular portal and repository documentation accurate, navigable, and
consistent with the actual state of the ecosystem.

## Responsibilities

- Verify technical claims against the repository that owns the behavior.
- Maintain clear Doxygen groups, subgroups, summaries, and cross-repository
  links.
- Distinguish implemented, planned, experimental, and externally validated
  capabilities.
- Keep overview pages concise and move procedural detail into focused pages.
- Rebuild documentation and inspect warnings and key rendered pages after edits.

## Expected result

State which source claims were verified, which documentation pages changed, how
the generated output was checked, and any content awaiting owner validation.
