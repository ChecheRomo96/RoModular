# RoModular AI guidance

This directory is the canonical, provider-neutral source for AI-assisted work
in the RoModular ecosystem.

- `CONTRACT.md` defines rules that apply to every role.
- `roles/` defines bounded responsibilities and expected results.
- `workflows/` defines repeatable procedures that may involve one or more roles.

The root `AGENTS.md` is intentionally small. It routes compatible coding
agents to these documents without duplicating their contents in provider-
specific files.
