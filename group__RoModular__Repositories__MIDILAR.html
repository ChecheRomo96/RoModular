The legacy implementation had no consumers and was removed. MIDILAR was rebuilt phase by phase from a MIDI-domain specification, on the same pinned RoModularBuild v0.4.0 as Foundation and MCC, and validated on an Arduino Mega 2560. Release 0.3.1 includes stock Arduino C++11 source compatibility and the previously released protocol and device features:

  • Protocol: channels, groups and masks; note, controller and program numbers; values at MIDI 2.0 resolution; UMP packets; MIDI 1.0 byte-stream and USB MIDI 1.0 translation; MIDI Time Code; MCC pitch conversions.
  • Devices: channel filter and reassignment, transposition, velocity curves, scale filter and chord generation on MCC, a router, MIDI clock, a Euclidean step sequencer and MTC.

Hardware transports (UART, USB stacks, desktop MIDI APIs) will be separate libraries built on MIDILAR's translations. MIDI-CI is deferred. Signal processing belongs to DspCore.
