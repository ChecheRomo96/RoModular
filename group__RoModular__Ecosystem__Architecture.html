Dependency Rules

  • Libraries depend downward on smaller, more general libraries.
  • Foundation contains no music-domain concepts.
  • MCC contains music theory but no MIDI protocol or device behavior.
  • DspCore contains signal processing but no MIDI or music-theory concepts.
  • MIDILAR owns MIDI and higher-level real-time music-system behavior.
  • RoModularBuild may provide build mechanics but never project policy.
  • RoModularAgents provides engineering guidance but is not a build or runtime dependency.
  • RoModular documents every layer but is not a build or runtime dependency.
