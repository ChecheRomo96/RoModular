RoModular

RoModular is a family of focused C++ repositories for portable software, embedded systems, music theory, and music technology. This site is the ecosystem-level map: it explains what each repository owns, how repositories depend on one another, and which projects are stable, active, planned, or retained only as legacy references.

  • Repositories links every repository and its own documentation.
  • Repository Status defines current maturity and next steps.
  • AI Agent Guidance explains the shared AI-agent contract.

One Portal, Independent Repositories

This portal does not replace repository documentation. Each project remains the source of truth for its API, build procedure, supported targets, tests, packages, and releases. RoModular records only ecosystem-level ownership, dependencies, compatibility, and navigation.
